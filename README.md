# Bank Customer Account Management System

## Description
A database-driven system to efficiently manage **bank customers, accounts, branches, and transactions**. Replaces manual record-keeping, ensuring accuracy, consistency, and easy retrieval of data.

## Features
- Add, update, delete, and retrieve customer, account, and branch records  
- Record and track transactions with SQL queries  
- Generate reports for account activity and branch performance  
- Ensure data integrity with constraints (PRIMARY KEY, FOREIGN KEY, UNIQUE)  
- Supports transactions with rollback and concurrency control  

## Technologies
- **Database:** MySQL  
- **Query Language:** SQL  
- **Tools:** MySQL Workbench  
- **OS:** Windows / Linux  

## Future Scope
- Web and mobile interfaces for remote access  
- Automated transaction alerts  
- Graphical reports and analytics  
- Integration with ATM/banking APIs
